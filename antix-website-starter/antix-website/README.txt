# Antix Ice Cream Website — Beginner Project

## Files
- `index.html`: website content and sections
- `style.css`: colors, spacing, layout and responsive design
- `images/`: optional folder for your own downloaded images

## Run in VS Code
1. Extract this ZIP file.
2. Open VS Code.
3. Select **File → Open Folder** and choose `antix-website`.
4. Open `index.html`.
5. If you have the Live Server extension, right-click `index.html` and choose **Open with Live Server**. Otherwise, double-click `index.html` in File Explorer to open it in your browser.
6. Keep the browser open. Save changes with `Ctrl + S`, then refresh if needed.

## Beginner learning guide
1. Change the title inside `<title>`.
2. Change the main heading inside `<h1>`.
3. Change colors in `style.css` under `:root`.
4. Replace image URLs in `index.html` with your own images.
5. Resize the browser to test desktop and mobile layout.

Note: this is a front-end demo. Search, shopping bag, booking, and order buttons are visual examples; the newsletter shows a demo confirmation. Real bookings, payments, or email subscriptions need a backend/service.
